# Learned Patterns

This directory holds patterns extracted from working sessions using the
`/learn` command. Each pattern lives in its own subdirectory with a
`SKILL.md` entrypoint following the standard skill format.

## Convention

```text
skills/learned/<pattern-name>/SKILL.md
```

Patterns here are validated -- they were used successfully in practice
before being extracted. Load them when their trigger context matches.
