# Discovery

Use before planning a business-facing web product.

## Inputs, Priority Order

1. User-provided name, city, links, services/products, prices, desired features.
2. Current website.
3. Public Google/Maps/business listing.
4. Public social pages.
5. Menu/catalog PDFs/images.
6. Public reviews and nearby competitors when useful.

## Rules

- Separate `Confirmed`, `User-provided`, `Assumed`, `Needs confirmation`.
- Do not fabricate facts, claims, reviews, addresses, hours, prices, or differentiators.
- If browsing, record source/date notes in planning docs.
- Do not scrape private/login-only pages.
- Summarize review themes; do not copy long reviews/menu text.
- For healthcare, avoid medical claims and sensitive patient data.

## Competitor Scan

Use only when it changes scope/copy/design. Capture above-the-fold promise, CTA, service/menu clarity, booking/order friction, trust signals, and missed opportunities. Practical conversion beats deep research.
