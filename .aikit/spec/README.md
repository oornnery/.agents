# .spec

Operational project state for agents.

Use `.spec/` for current work metadata, validation notes, handoff context, and short-lived implementation state. Keep durable product or architecture decisions in `SPEC.md`, `DESIGN.md`, `TODO.md`, or `.mem/decisions.md`.

Rules:

- keep entries concise and dated
- record verified facts, not guesses
- preserve open questions explicitly
- do not store secrets
- update before stopping when meaningful work remains
